# Check Command Service
curl -s http://localhost:8080/health



# Check Query Service
curl -s http://localhost:8081/health


Create Products
Product 1 (Laptop - Electronics):
curl -s -X POST http://localhost:8080/api/products \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Gaming Laptop",
    "category": "Electronics",
    "price": 1200.00,
    "stock": 50
  }'

Product 2 (Office Chair - Furniture):
curl -s -X POST http://localhost:8080/api/products \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Ergonomic Chair",
    "category": "Furniture",
    "price": 250.00,
    "stock": 200
  }'



Create Orders (Command Service)
Order 1: Customer 1 buys 1 Laptop
curl -s -X POST http://localhost:8080/api/orders \
  -H "Content-Type: application/json" \
  -d '{
    "customerId": 1,
    "items": [
      {
        "productId": 1,
        "quantity": 1,
        "price": 1200.00
      }
    ]
  }'


Order 2: Customer 1 comes back and buys 2 Chairs
curl -s -X POST http://localhost:8080/api/orders \
  -H "Content-Type: application/json" \
  -d '{
    "customerId": 1,
    "items": [
      {
        "productId": 2,
        "quantity": 2,
        "price": 250.00
      }
    ]
  }'


Order 3: Customer 2 buys 1 Laptop and 4 Chairs
curl -s -X POST http://localhost:8080/api/orders \
  -H "Content-Type: application/json" \
  -d '{
    "customerId": 2,
    "items": [
      {
        "productId": 1,
        "quantity": 1,
        "price": 1200.00
      },
      {
        "productId": 2,
        "quantity": 4,
        "price": 250.00
      }
    ]
  }'



Check Sync Status (Query Service)
curl -s http://localhost:8081/api/analytics/sync-status



Fetch Analytics (Query Service)
